### 1. 00 Counterfactual rewards promote collective transport using individually controlled swarm microrobots
### 反常规奖励，在假设系统中移除一个智能体，观测最终结果与未剔除的差异，得到该智能体的实际奖励
```text
    作者提出，根据自然界中生物的群体决策，我们可以学习构建类似的机器人群体，通过对个体独立控制，模拟个体决策和依据环境做出的
改变。然而这在微型机器人领域却存在挑战：传感器、控制器等无法做到足够精密。于是有人提出了改变环境进而控制微观粒子进行群体行为
的想法，并取得了成效。然而可供选择的集体运动模式受限制，微观的简单物理碰撞不能复刻宏观个体的独立决策。继而提出了两大挑战：布
朗运动导致的热噪音，多机器人之间不可预测的强烈物理耦合（如环境的轻微变化导致系统的剧烈变化）。
    顺势提出MARL（Multi-Agent Reinforcement Learning）。MARL不需要确定的优化模型，可以自动完成任务。MARL在训练时优化神经网
络的参数，迁移时只需修改奖励函数（Reward）即可，效率提高。但是不能平均分配奖励，会产生“懒Agent”，降低系统效率。手动设置奖励函
数被作者证实不利于提高模型的性能，且需要按照任务专门设计，因此作者提出了CRs：在假设环境中，回到上一个时间步，将多智能体中移除一
个智能体，观察假设系统总体与真实系统的差值，即可推断该智能体的贡献。
    无需关注物理层的实现，只需考虑算法思想层面的学习即可。
    智能体间不存在通信机制，为了方便智能体观察和运动，在智能体的视角前180度平均分为5个区域，观察其他智能体的运行和位置信息，以
及5个自身划分杆的信息。智能体的输入只有上述10个维度。每个独立的智能体的决策共享同一个浅层神经网络。    
```
### 补充一下RL的基础
```text
概念性问题：Agent作为一个古老概念早就存在了，称为"智能体",强化学习包含：Agent（智能体）、Environment（环境）、State（状态）、
Action（动作）、Reward（奖励）、Policy（策略，在State下Agent如何行动）、Value（价值，处于State时未来收益的累计）、Q-value
（采取动作Action后未来的价值）、Trajectory（轨迹）、Exploration/Exploitaion（探索/利用）、Discount Factor（折扣因子）。
```

### 2. 01 Synergy Pattern Diversifying Oriented Unsupervised Multi-agent Reinforcement Learning
### 训练时最大化不同的协同模式，生成不同的策略，多智能体集群可以用更多的skill解决问题

```text
    作者发现单智能体的强化学习算法只能让一个智能体学到skill，若将URL套用到多智能体的无监督（无人工目标）强化学习，由于多智能体
之间存在相互作用，总体的目标与学习到的skill并不完全适配。作者提出了将图与多智能体学习相结合的SPG，SPG表示每时刻智能体之间的关系；实验里
作者用观测间欧氏距离作为边权，进而提出了SPD。
     一些已有 MARL 方法泛化较差，而部分图方法主要用于通信，可能增加去中心化执行成本；作者的方法完美解决了上述问题。URL可以很好的适配单
智能体学习，但是训练多智能体就会乏力；作者的SPD可以解决。
    预备知识：作者采用CTDE范式，即训练阶段为全局视野，测试阶段为局部视野。根据最优传输OT，类比到两张关系图的对比。
    在SPG（协同模式图）中，顶点代表智能体，边权代表智能体间的关系，由协同模式函数产生且协同模式函数非负。作者从两个SPG分布中采样图的差
异来表示两个协同模式之间的差异。用Gromov-Wasserstein的差异构建代价矩阵，然后将两批图的代价矩阵元素进行匹配，计算差异，取最小值作为两不
同协同模式差异的近似值。需要注意的是两批SPG图的时间步并不一致，需要全部匹配计算。为了在无监督下训练出多样的协同模式，作者最大化最相似的
SPG之间的差异。
    SPD基于QMIX实现，每次随机选择一个协同模式，然后差异化这个协同模式。
    SPD效果很好，作者在实验中证明了其在无监督多智能体协作中能学习的有意义的协同模式，可以加速下游任务的训练。局限在与物理实现上仍需要
人工监督，否则可能会有安全事故。 
```

### 3. 02 Discovering Generalizable Multi-agent Coordination Skills from Multi-task Offline Data
### 仅利用多任务离线数据提取任务无关的协同技能，和训练一个可以决定使用何种协同技能的高层，最后由单智能体执行对应行动
```text
    传统多智能体解决下游问题的方式需要高昂的交互才能微调模型，调整策略，对此作者提出了ODIS：利用离线数据训练出泛化性能很好的多智能体集
群。集群学习到了非任务专用的通用型技能，并分别派发至智能体，形成单智能体独立决策方法，可以快速适配下游任务。
    作者以星际争霸为例，提出了"协同技能"的概念:能帮助在多种任务中实现协同的任务无关性技能。
    当前主流多在研究微调策略或多任务同时学习，将模型部署到未见任务的泛化策略是项挑战。而现有的基于离线数据的多智能体训练策略过于保守，
在面对未见任务时性能会大幅下降。ODIS框架中存在学习状态编码器和动作编码器，用于根据策略选择协同技能并执行对应的动作。
    算法实现细节交由后续完成。
```
