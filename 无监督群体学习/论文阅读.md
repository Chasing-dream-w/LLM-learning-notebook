# 本文用于记录学习的论文思想、方法等

### 1. Counterfactual rewards promote collective transport using individually controlled swarm microrobots

```text
作者提出，根据自然界中生物的群体决策，我们可以学习构建类似的机器人群体，通过对个体独立控制，模拟个体决策和依据环境做出的改变。然而这在微型机器人领域却存在挑战：
传感器、控制器等无法做到足够精密。于是有人提出了改变环境进而控制微观粒子进行群体行为的想法，并取得了成效。然而这无法大规模应用——环境控制不可能是简单且易拓展的
，微观的简单物理碰撞不能复刻宏观个体的独立决策。

```
